# Roll a Ball Game

A simple 3D ball rolling game developed with Unity. Players control a sphere to collect items in the scene, experiencing basic 3D game mechanics.

## Game Demo

Watch the gameplay video:

[![Roll a Ball Game Demo](https://img.youtube.com/vi/2wpCrBSPMZI/0.jpg)](https://youtu.be/2wpCrBSPMZI)

## Features

- Intuitive game controls
- 3D physics effects
- Collectible scoring system
- Smooth ball movement control

## Download and Installation

### Windows Version
- System Requirements: Windows 10/11
- Download: From `windows-version` branch
- How to Run: Execute `Roll a Ball.exe`

### macOS Version
- System Requirements: macOS 10.15 or higher
- Download: From `macos-version` branch
- How to Run: Double-click `Roll a Ball.app`

## Controls

- Use arrow keys or WASD to control the ball movement
- Collect all cubes to win
- Press ESC to pause the game

## Development Tools

- Unity6
- Unity's built-in physics system
- C# programming language

## Branch Information

- `windows-version`: Game version for Windows platform
